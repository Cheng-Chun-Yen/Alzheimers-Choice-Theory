# V1.1 Final Draft

This directory contains the official **V1.1 Final Draft** publication package for **Alzheimer's Choice Theory (ACT)**.

## Included files

- **Alzheimers-Choice-Theory-V1.1-Final-Draft-ZH.pdf**  
  Authoritative Chinese original text.

- **Alzheimers-Choice-Theory-V1.1-Final-Draft-EN.pdf**  
  English companion version derived from the Chinese authoritative text.

- **Alzheimers-Choice-Theory-V1.1-Final-Draft-math.pdf**  
  Mathematical / formalized companion version derived from the same theoretical structure.

- **ACT-V1.1-Publication-Manifest.pdf**  
  Publication manifest for the V1.1 package, including release and integrity-reference information.

## Publication identity

- **Concept DOI:** `10.5281/zenodo.17388753`
- **Version 1.1 Final Draft DOI:** `10.5281/zenodo.19083901`

## Authority and interpretation

The Chinese version is the **authoritative source text** for V1.1.  
The English and mathematical versions are companion representational forms derived from the same theoretical framework.  
In case of interpretive ambiguity, the Chinese original text takes precedence.

## Notes

This folder is intended to preserve the V1.1 Final Draft publication package as a stable release unit for public reference, citation, and verification.
