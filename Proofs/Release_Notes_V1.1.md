## Release Summary

V1.1 Final Draft is the current public release of **Alzheimer's Choice Theory (ACT)**.

This version is a revision based on **V1.0 Final Draft**, incorporating textual refinements, errata corrections, and clearer formulation of structural and falsifiability statements, while preserving the same core logical structure, causal topology, principal mechanisms, and principal conclusions.

This revision does **not** constitute a new theory or an independent work.

## Core Theoretical Identity

ACT maintains the same closed-causal topology:

`NT → D → AD`

Where:

- `NT` = long-term Non-Thinking State
- `D` = Neural Functional Decline
- `AD` = Alzheimer's Disease

The theory continues to employ a three-layer progressive architecture:

1. **The Foundational Layer**
2. **The Mechanism Modeling Layer**
3. **The Applied Extension Layer**
